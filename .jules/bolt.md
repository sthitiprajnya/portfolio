## 2025-06-07 - Scroll Stability Check and Layered Early-Exits
**Learning:** In high-frequency (60fps) Canvas 2D animation loops, performing proximity checks against multiple DOM-relative targets (requiring vertical coordinate math) on every frame is wasteful when the user is not scrolling. By implementing a "Scroll Stability Check" using a `useRef` to track the last vertical position, we can skip expensive math and logic updates when the page is stationary, while still allowing for fluid frame-by-frame rendering (e.g. constant blitting).
**Action:** Implement `if (Math.abs(current - last) < 0.1) return;` style gates for expensive calculations in hot loops that depend on scroll or mouse position. Combine this with Stage-2 early-exits for layered animations to minimize CPU load during idle or non-triggered states.
